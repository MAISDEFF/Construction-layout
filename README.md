# Construction Company Landing Page 🏗️

Адаптивная верстка лендинга для строительной компании.

## 📌 О проекте

Одностраничный сайт строительной компании с информацией о проектах, услугах, партнерах, отзывах и контактах.

Проект выполнен в рамках практики HTML/CSS верстки.

## 🛠 Технологии

- HTML5
- CSS3
- Flexbox
- Grid
- Responsive Design
- Materialize

## ✨ Реализовано

- Главный экран
- Блок со статистикой
- Карточки проектов
- Блок услуг
- FAQ
- Отзывы клиентов
- Контактная информация
- Адаптивная верстка
- Material Box
- Modals
- Sidenav
